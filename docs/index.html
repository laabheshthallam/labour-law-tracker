📬 Telegram & Gmail Daily 6:00 PM Alerts

The system runs automatically every evening at 6:00 PM IST via GitHub Actions and sends curated 40-50 word summaries directly to your Telegram bot and Gmail digest.

1. Telegram Instant Alerts

  • Create a bot on Telegram via @BotFather and get your token.
  • Get your Chat ID via @userinfobot.
  • Add secrets TELEGRAM_BOT_TOKEN and TELEGRAM_CHAT_ID to your GitHub repository or .env file.

2. Gmail Daily HTML Digest

  • Generate a Google App Password from your Google Account → Security.
  • Add secrets EMAIL_ADDRESS, EMAIL_APP_PASSWORD, and EMAIL_TO to GitHub Secrets.
